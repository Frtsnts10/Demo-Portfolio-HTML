# Minimalist Dev Portfolio Template (Vanilla Edition)

A hyper-fast, zero-dependency, minimalist HTML/CSS portfolio template built for developers. This template is designed to achieve a perfect 100/100 Lighthouse score by eliminating heavy frameworks and relying entirely on Semantic HTML, CSS Variables, and Vanilla JavaScript.

## 🚀 Features
- **Zero Dependencies**: No React, no Tailwind, no jQuery, no external icon libraries.
- **Lightweight**: Total assets (HTML, CSS, JS) under 100KB (excluding images).
- **Dark/Light Mode**: Built-in theming using native CSS Custom Properties.
- **Data-Driven**: Easily manage your profile, skills, and projects by editing a single `data.js` file.
- **Responsive**: Fluid layout using CSS Flexbox and Grid, mobile-ready.
- **Native Animations**: Smooth transitions and hover effects using pure CSS.

## 🛠 Getting Started

1. **Clone or download** this repository.
2. **Open `index.html`** in your browser. (Since it uses ES Modules for `data.js`, you might need to serve it via a local web server like Live Server in VSCode or `python -m http.server`).
3. **Edit `data.js`**: Update the `portfolioData` object with your own information, skills, and projects.
4. **Deploy**: Host it for free on GitHub Pages, Netlify, or Vercel. No build step required!

## 📂 File Structure
- `index.html`: Semantic HTML structure.
- `style.css`: Core styling, CSS variables, layout, and animations.
- `mediaqueries.css`: Responsive design rules.
- `script.js`: Vanilla JS for dark mode logic and DOM rendering.
- `data.js`: The central data store for your portfolio content.
