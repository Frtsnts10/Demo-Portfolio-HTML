# Minimalist Dev Portfolio Template (Neo-Brutalist Edition)

A hyper-fast, zero-dependency minimalist developer portfolio template featuring a modern Neo-Brutalist Bento Grid layout, floating navbar, and dark mode. Built purely with Vanilla Web Tech (HTML, CSS, JS).

## 🚀 Features
- **Bento Grid Architecture**: Modern dashboard-style grid layout that seamlessly adapts to different screen sizes.
- **Neo-Brutalist Aesthetics**: High contrast borders, hard drop shadows, pill-shaped elements, and fluid giant typography.
- **Zero Dependencies**: Absolutely no React, no Tailwind, no jQuery, and no external font/icon libraries required.
- **Native Interactivity**: Smooth "Fade-Up" scroll reveals using the Intersection Observer API and a pure CSS marquee background.
- **Dark/Light Mode**: Built-in, high-contrast theming powered by native CSS Custom Properties and `localStorage`.
- **Easy Content Management**: Update your profile, skills, and projects by editing a single global `data.js` file.

## 🛠 Getting Started

1. **Clone or download** this repository.
2. **Open `index.html`**: Simply double-click the `index.html` file to open it in your browser. (No local server required!).
3. **Edit `data.js`**: Update the `portfolioData` object with your own information. The DOM will automatically render your changes into the Bento Grid.
4. **Deploy**: Host it for free on GitHub Pages, Netlify, or Vercel. No build step required!

## 📂 File Structure
- `index.html`: Semantic HTML structure and inline SVGs.
- `style.css`: Core styling, Neo-Brutalist design tokens, Bento Grid layout, and animations.
- `mediaqueries.css`: Responsive design rules for mobile and tablet views.
- `script.js`: Vanilla JS for scroll animations, dark mode logic, and dynamic DOM rendering.
- `data.js`: The central data store (loaded globally) for your portfolio content.
